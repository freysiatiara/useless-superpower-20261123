# Useless Superpower — One Line, Zero Use

Entry for the make.fun bounty **"One Line, Zero Use: The Useless Superpower Sprint"** — one original line, at most 200 characters, naming a hilariously useless superpower.

`main.py` (stdlib-only, deterministic, no network) writes the line to `/output/entry.txt`:

> I can teleport anywhere instantly, but only to the exact spot I'm already standing in.

The ultimate power, with absolutely nowhere to go.
